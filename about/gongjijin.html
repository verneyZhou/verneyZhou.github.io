                  一篇文章带你玩儿转公积金

                  # 一篇文章带你玩儿转公积金

                  最近打算公积金贷款买个二手房玩玩，但对于目前买房的政策可以说是一无所知，知无不言，言不知从何说起...翻遍了网上各种攻略帖子，发现各种五花八门的情况都有，买房流程更是越看越头大...就在我犹豫要不要就这么租房过一辈子的时候，我看着我那日渐肥硕的公积金余额，怎么说也得让它花在它该花的地方；但面对复杂的公积金贷款流程，我才意识到，原来想花公家的钱真的没有那么容易...于是痛定思痛，我决定好好搜集资料，好好整理下公积金贷款流程，以上就是这篇文章的由来~

                  # 公积金贷款买房流程

                  # 公积金异地贷款

                  买成都的二手房，可以用北京的公积金贷款，需要咨询成都的公积金政策

                  # 公积金异地提取

                  买成都二手房，提取北京公积金，需要咨询北京这边的政策

                  # 公积金贷款

                  个人贷款额度：账户余额*25，最高60w

                  利率：2.1％（5年内），2.6％

                  首付比例：不低于20％

                  申请条件：单位连续缴纳超过6个月

                  流程：看房☞买房，签购房合同☞付首付☞签贷款合同去线下申请，提交材料☞银行调查☞中心审批☞跟银行签贷款手续☞领房产证，办抵押手续☞银行领抵押材料，发放贷款☞领借款合同☞公积金提取

                  还款方式：等额本息，等额本金

                  可提前还款，无次数限制，可自己准备单独的还款银行卡

                  # 公积金异地转移

                  需要上一个城市封存满6个月，且 当前城市正常缴纳6个月才能申请

                  支付宝线上申请即可，钱和年限都能转过来，过几天就能到账了

                  # 公积金提取

                  购房提取：不得超过首付款，只可提取未纳入贷款额度计算的部分，购房合同备案后五年内可提取，每月最多一次

                  偿还贷款提取：组合贷买房后，可申请，不得超过已还款金额，可多次申请，可一月提取一次

                  • 直冲本息：直接从公积金账号里扣
                  • 定额提取：中心把钱转到自己个人账户

                  租房提取

                  上面三种提取方式一年只能选一个

                  # 买房方案

                  4月，离职，入职成都
5月，查询北京公积金账户封存状态是否为集体封存，否的话打百度人事电话让改下
6月~9月，看房选房，确定区域位置和小区
10月，公积金异地转移，把北京公积金的钱转到成都；北京公积金账户估计有60w左右
11月，公积金贷款买房，房屋总价110w左右，先凑钱付首付50w，办张卡用于还房贷60w，并提前准备两月的月供打到卡
12月，之后申请购房提取首付款50w（自用）；第二年再申请公积金按月还贷提取，让公积金每月按月供打到我还款卡上

                  # 问题记录

                  • 问题1：办理公积金贷款后，是公积金中心每月自动从我的公积金账号里划走月供？

                  贷款和还贷是分开的，满足贷款资格就可以贷款，贷款时需要提供一个自己的还款账号；之后还款的话可以按【购房提取】或【按月还贷提取】申请提取，一年只能选一种

                  • 问题2：异地转移的公积金可以提取出来吗？

                  可以提取，成都没有限制

                  • 问题3：组合贷款买房后办理公积金提取，是每月提取不可超过首付，还是提取总额不可超过首付？

                  每月提取不可超过首付金额，意思是首付50w，只要公积金账户里钱足够的情况下，每月都可以提取不超过50w

                  • 问题4：比如我今年11月通过组合贷款买房，我可以在12月通过购房提取提取部分金额吗？

                  可以，但该年就不能用公积金还贷了
