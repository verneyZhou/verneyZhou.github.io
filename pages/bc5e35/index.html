# 05 · 第一章正文

《批改者》· 第一章：课堂 草稿 v0.1（约 3,000 字）· 依据 02-逐幕大纲.md 第一幕第 1 章

老周一夜没睡好。

凌晨从办公室回去，躺下又起来，起来又躺下。窗外的天空已经泛起蟹壳青，他才迷迷糊糊合了一会儿眼，梦里全是划来划去的轨道线，一条条往同一个方向弯。闹钟响的时候，他脑子像被塞了一团棉花，太阳穴一跳一跳的。

但他还是七点二十进了教学楼。

他心里装着那道题。昨晚他把数据库翻了个底朝天，越是确认"教材参数在哪儿都不存在"，越是坐不住。他想在课堂上把这道题再讲一遍——不是给许明一个交代，是想亲眼看一看：全班四十多个学生，是不是真的只有一个人看得出这道题不对劲。他教了二十年书，还从没遇到过"标准答案本身出了问题"的卷子，他要亲眼确认，这不是他一个人睡糊涂了做出来的梦。

县城中学的高三，课表排得密，上午第一节就是物理。老周端着搪瓷缸进来的时候，教室里还没安静下来——后头几个男生在传一本《五年高考三年模拟》，前头两个女生对着抄昨天的英语改错。许明坐在靠窗第二排，正低头翻一本蓝皮的观测本，听见脚步声才合上，抬眼看讲台。

老周把搪瓷缸搁在讲台上，没急着说话。他站在那儿，先扫了一遍全班。四十多张脸，有的还带着没睡醒的浮肿，有的已经绷紧了准备挨考。他把昨天那沓模拟卷子拍在讲台上，卷子边角还卷着，是批改时来回翻的。

"昨天的卷子，"他说，"其他题我不多讲了，对答案就行。有一道题——"他顿了顿，"我想多花两分钟，听你们说说想法。"

他在黑板上把那道题抄下来。

近地天体轨道计算。天体的质量、轨道参数都给了，问它在某个时刻的位置。他抄得很慢，粉笔在黑板上划出白痕，一笔一笔。教室里安静下来，只听见粉笔和黑板摩擦的细响，还有窗外操场上体育老师吹哨子的声音，隔着一层楼，闷闷的。

抄完，他拍了拍手上的粉笔灰，转过身。

"这道题，昨天全班只有一种答案。"他说，"但我今天想问问——有没有人，觉得这道题哪儿不太对？"

没人说话。

前排几个学生低下头，假装在看卷子。后排传那本教辅的男生把书塞回桌洞，也低下头。许明没有低头，他看着黑板，看得很慢，从题目看到那个轨道参数，又从头看一遍。然后他举手了。

"周老师，"许明站起来，声音不大，但教室里每个人都听得见，"这道题，参数有问题。"

教室里"嗡"地一下，像是水烧开前的声音。几个学生抬起头，互相交换眼神。后排有个男生没忍住，小声说了句"班长你魔怔了吧"，被同桌用胳膊肘捅了一下，又缩回去。

老周没有立刻说话。他看着许明。这孩子站得笔直，校服领子翻得整整齐齐，就是眼睛底下有两道青，跟老周自己差不多——也是没睡好的样子。

"说说，哪儿有问题。"老周说。

"它给的这个轨道参数，"许明说，顿了一下，"和真实情况对不上。"

"你怎么知道和真实情况对不上？"

"因为我算过。"许明说，"这个学期我在做小行星巡天，就是天文社挂名参加的那个国际项目。我分到的一颗近地小行星，编号开头是 2024——正好就是这道题里用的那颗。我按它预报的位置去找，找不到。偏了。我把观测数据带回来了。"

他从桌洞里掏出那沓打印纸，举起来。纸页哗啦啦地响，纸边卷着，上头画着几条手绘曲线。

教室里更安静了。有人偷偷扭头看许明手里的纸，有人看老周，等着他发火——在高三的物理课上，一个学生当着全班说"教材参数错了"，这几乎等于跟老师叫板。按照他们熟悉的那套规矩，接下来应该是老周沉下脸，说"你先坐下，这道题按教材讲，下课再谈"。

但老周没有沉下脸。

他走过去，接过那沓纸，翻了翻，又递回去，声音很平："你说得对，这个参数是有问题。我昨晚也核过。"

教室里彻底安静了。连那个传教辅的男生都抬起头，眼睛瞪得溜圆。

"但是，"老周看着全班，"问题在哪儿，还没搞清楚。所以这道题——"他把黑板上的题目画了个圈，"我们换个讲法。我把这道题留成思考题，明天上课，我要听到至少三种不同的说法。"

下课铃响了。学生们陆陆续续站起来，有人往外走，有人还在偷偷回头看许明。许明被三个同学围住，七嘴八舌地问"你怎么发现的""是不是真的错了""那考试怎么办"。他抿着嘴，一五一十地答，声音还是不大。

老周端着搪瓷缸回了办公室。关上门，他把门反锁了，又站了一会儿，才走到自己那张桌子前坐下。

他打开电脑。

验算，这是他现在唯一能做的事。许明的说法，他昨晚在数据库里已经核过一遍——教材的参数确实对不上。但他不能只靠一晚上、一个网站就下结论。他是个老师，他教了二十年"物理是描述"，不能因为一道题就慌慌张张地宣布天塌了。他要自己动手，把这事查个水落石出。

他先做第一遍：教科书公式重算。

他铺开一张草稿纸，把教材给的参数抄上去，老老实实地按高中物理的轨道公式推演。这一步做得慢，因为他在有意放慢，想看看自己有没有算错。二十分钟后，他算完了，答案和全班昨天交上来的一模一样——教材参数，标准答案，天经地义。

他没有停。他拿过许明的观测记录，把许明反推的那组参数也抄在另一张草稿纸上，用同样的公式推了一遍。推出来的结果，和许明记录上的曲线对上了，严丝合缝。

"如果按许明的参数，"老周盯着两张草稿纸，自言自语，"这颗星就在它该在的地方。如果按教材的参数——"他拿起第一张纸，"它根本不该在那。"

他把两张纸并排放好，又开了电脑上那个用了十年的星图软件。这软件是他当年在师范大学读书时自己写的小程序，后来他教天文社，又给它添了几个功能——能算轨道，能模拟天体运行，不算先进，但够用，也够他用了二十年。他把许明的参数输进去，让软件按万有引力一天一天地往前推，推这颗小行星未来三百天的轨迹。屏幕上，一条白色的线慢慢画出来，越过屏幕边缘，又绕回来，像一只笨拙的蚕在吐丝。

然后他调出小行星中心公开的历史观测数据，把那颗小行星自 2019 年第一次被拍到以来的每一份记录都导出来，一条一条叠在屏幕上。

白线穿过那些观测点。穿过第一个，穿过第二个，穿过第三个……一个点都没偏。

老周靠在椅背上，盯着屏幕，看了很久。窗外太阳已经升起来了，照进办公室，把屏幕上那条白线照得有点发白。他伸手去拿搪瓷缸，缸沿是凉的，茶早喝完了，只剩一层褐色的茶渍。他放下缸子，又去看那两张草稿纸。

教科书公式，他算出来是教材的答案——这是基准，先放在一边。 许明参数，他算出来是许明的答案。 软件推演，推到的是许明的答案。 历史观测，落的是许明的答案。

三样东西，指向同一个地方：许明的答案。而教科书那套标准答案，像一条画在纸上、从来没人去过的路。

"可能是巧合。"老周对自己说。他是个老师，他知道科学的第一步永远是怀疑自己。也许许明的观测有误差，也许那个国际项目的数据本身有问题，也许这颗小行星被什么东西扰动过——引力、太阳风、别的天体，都可能让轨道偏一点。巧合的可能性没有排除完，他不能下结论。

但另一个念头，像针一样，怎么也按不下去。

如果这不是巧合呢？

他坐了很久。办公室里有阳光、有灰尘、有楼下操场传来的广播体操的喇叭声，一切都正常得不像话。他忽然想起大学时的事——他差三分没考上研究生，灰溜溜地收拾行李回县城。临走那天，程远把他的《理论物理》笔记塞回他包里，说了一句话。他当时没放在心上，这些年也一直没想起来。

老周站起身，走到书架前。那本笔记就夹在《普通物理学》和《原子物理》之间，蓝皮，边角都磨白了，页沿被水泡过，起了一层毛。他抽出来，翻开扉页。

扉页上有一行字，钢笔写的，墨水洇开了一点，但还是能认出来。是程远的笔迹，大学四年，他太熟了：

"老周，要是哪天你发现，描述和宇宙打架了——记得写信给我。程远。"

老周捏着笔记，站了很久。

他和程远这几年一直有联系。不像年轻时候那样天天见面，但隔三差五会在微信上聊两句——程远偶尔转发一张天文台的深空照片，配一句"看看，比你那县城星星清楚吧"；老周就拍一张学校操场上空的夜空回过去，说"清楚是清楚，就是没咱这儿的人味"。逢年过节，两个人雷打不动地互相发一句"老同学，保重"。至于更早那十几年——那又是另一段故事了，两个人谁都没再提。

老周掏出手机，点开和程远的聊天窗口。最近一条还是上周，程远发来一张刚处理好的蟹状星云照片，他没回。他盯着输入框，把昨天到今天的事，挑着能说的，一个字一个字敲进去：一道教材上的轨道题，一个学生反推出来的参数，历史数据库里对不上的那条轨道。写得慢，删改了好几次，最后发出去的时候，手指顿了一下。

消息不长，末尾他多打了一句：

"你还记得毕业那年，你在我《理论物理》笔记扉页上写的那句话吗？'要是哪天发现，描述和宇宙打架了，记得写信。'我这儿，好像真遇上了。"

发完他把手机扣在桌上，站起身，走到窗边。窗外太阳已经升起来，把校园照得亮堂堂的，楼下有学生抱着书往教室跑，一切正常得不像话。他站了一会儿，又回去看那两张草稿纸，心里说不清是盼着回复，还是怕回复。

程远的回复来得很快。快到老周以为他也正捧着手机。

"老周。"程远只回了一句，后面跟着一个省略号，停了几秒，又补了一条，"你等着。我发你一个东西——一个纯粹的数学结构，不涉及任何背景，你就当帮我验一道题。你看一眼，行吗？"

老周盯着"不涉及任何背景"这几个字，又看了看桌面上那两张草稿纸。

"行。"他回，"你发过来吧。"

程远没再多说。几分钟后，一个文件传了过来，没有文件名，后缀是一串字符。老周点开，屏幕上跳出一页密密麻麻的算式。

他本来只是打算看一眼。但第一行式子还没看完，他就停住了。

那个结构，他见过。

不是今天见过的。就在昨天——在他自己那张草稿纸上，在许明反推出来的那组参数里。那道"错题"背后的"干净解"，此刻正安安静静地躺在这页算式里，像一条河，从程远那边流过来，和他这边汇在了一起。

老周握着手机，盯着屏幕，很久没有动。

两个人，一个在县城，一个在不知什么地方，隔着一千多公里，在同一个月里，撞上了同一件说不清的事。

他想起程远那句话后面跟的省略号。他忽然觉得，那没说完的话，可能比这道题本身还要重。

老周把搪瓷缸里的凉茶倒掉，重新泡了一杯。他坐回桌前，把那页算式又从头看了一遍。

——第一章完——
